# 模型形象素材（跨游戏共用）

「一个模型 = 一个家族 = 一个 logo + 一个音色 + 一个形象」里的**形象**部分。
五子棋、中国象棋、狼人杀共用同一套家族形象；家族匹配只有 `../models.mjs` 一处。

## 两个档位

| 档位 | 规格 | 用在哪 |
|---|---|---|
| `full/` | 320×480（2:3）带 alpha WebP | 狼人杀席位舞台的席卡；**标准档**执行者卡（66×86，在模型名左侧） |
| `bust/` | 320×320 方形带 alpha WebP | **紧凑档**执行者卡（46×58，象棋竖屏，放卡片右侧） |

命名：`<家族>`、`<家族>-2`、`<家族>-3`（每家族三套变体，供同族多席不撞脸），
以及 `<家族>-dead`（出局档，只服务狼人杀席卡，**没有** bust 档）。

## 为什么是带 alpha 的 WebP

原立绘是 **RGB JPEG、没有 alpha，背景是纯黑 `(1,1,1)`**。
直接放到白色侧栏上就是一块黑方块——这正是「形象要只有人物、没有底板」这条版式口径的前提。
`test/model-art.test.mjs` 会解每一张图的通道，退回不带 alpha 的格式即失败。

## 怎么来的

由 `.prototypes/arena-model-art/derive.mjs` 从 `../werewolf/characters/*.jpg` **派生**：

- 黑底键（背景实测 1—18，最暗衣物也在 30 以上，所以阈值可以取很紧）；
- 连通种子**只取上半幅与左右边距**——半身立绘在画幅底部被裁切，从底边取种子会把衣摆当背景吃掉；
- 收缩 1px 去白边 + 底部渐隐（被裁切处不留硬边）；
- 实测体积：40 张 full 共 591 KB，是原 JPEG（568 KB）的 **1.04×**。

**注意：这一批不是重新生成的立绘**，取景仍是原来的半身构图。
将来换成原生带 alpha 的立绘时，`derive.mjs` 会直接透传（只做压缩），不需要改代码。

派生脚本属于素材生产线，与出图脚本（`.prototypes/arena-art-drafts/gen-variants.sh`）放在一起，
不进产品包。改完素材必须跑 `npm run arena:build` 重新生成 `../model-art.mjs`
（`test/model-art.test.mjs` 会拦住不同步）。
