## 查阅原文

在仓库根目录查找历史提交；以下是已移除记录的示例：

```sh
git log --all --oneline -- docs/14-spoken-video-full-pipeline.md
git show <commit>:docs/14-spoken-video-full-pipeline.md

git log --all --oneline -- docs/ai-arena.md
```
