| 2026-10-08 起 | 成片复用：同一组渲染输入不再重复渲染 | 比赛终局后内容冻结、渲染又是确定性的（`video.mjs` 关掉全部 CSS 动画、随时间的量由 `markup.mjs` 按帧内联），此前每次点击「导出 MP4 / 导出有声 MP4」都会重跑 bundle + 逐帧渲染 + 混音，只有配音按句缓存。现在导出前按渲染输入算键——参与渲染的源文件摘要 + `PIPELINE_VERSION`、`replayData` 摘要、画幅、每手秒数、是否配音（带响度版本）——键相同直接交回上次的成片；索引为 `match.json` 的 `exports`，每场最多 8 份、超出连文件淘汰。产物改用带键文件名（`video-<键>.mp4` / `replay-<键>.html`），顺带修掉无声/有声、不同每手秒数共用一个 `<画幅>.mp4` 互相覆盖的老问题；老记录没有 `file` 字段照旧按画幅命名下载，新导出成功后清掉旧命名文件。客户端按索引把主按钮换成「下载」，另给「重新渲染」入口；`videoChunk` 也认缓存键，并拒掉 `__proto__` 这类原型链键。无声离线回放不进缓存（纯函数现算、零成本）。见[AI 竞技台](ai-arena.md#成片复用) |
| 2026-10-08 起 | 狼人杀席位舞台改为逐手回放 | 观战页的播放/拖动此前对狼人杀无效：席位舞台只读 `match.state`（整局唯一、比赛结束后就是终局的那份快照），点播放从头播时画面一直停在「好人获胜 + 全部出局」，而棋盘类由 `frameAt` 现推手数所以正常。席位存活不能像棋盘那样从落子序列现推——`move.action` 只写「狼刀 3 号」，3 号是否真的出局取决于后面那手女巫有没有用解药、投票是不是平票、猎人有没有开枪。新增包根目录的 `werewolf-projection.mjs`：用 `config.seed` + `config.seats`（缺省按选手数推断）+ 已提交动作序列逐手 `apply` 出每一步之后的公开局面快照（只带 `phase`/`hunterCause`/`day`/`players`/`narration`/`publicLog`/`lastNightDeaths`/`winner`），观战停在 `currentStep` 就画那一刻的存活、天数、阶段、出局与主持人台词，胜负面板与 `胜 / 负` 徽标只在最后一手出现，`data-act` 的出局强调也精确落在真正死人的那一手。`replay/data.mjs` 改为在同一份投影上摘掉快照，离线回放与视频产物逐字节不变（已用四场真实记录比对）。身份标记取落盘那一份而非重放重发的牌，档位不可重放或重放失败时整体退回 `match.state`（即旧行为），客户端按「同一场比赛 + 已提交落子数」记忆化，轮询与思考计时不重跑规则。同时把规则引擎用的 `structuredClone` 加进客户端作用域白名单、把新模块加进 `RENDER_INPUTS`；见[AI 竞技台](ai-arena.md#画面与视频) |
| 2026-10-08 起 | 主持人台词锚点改「本手开场」 | 离线回放里出现过「6 号还在发言，主持人已经先说『发言结束，请投票放逐一名玩家。』」：规则层在最后一位发言者的 `apply` 里写结算播报，展示层却按「主持人先说、选手后说」渲染同一帧，于是结算被提前一手。`werewolf-projection.mjs` 的逐手 `host` 改为取**这一步开始时**生效的台词（结算播报归下一步），观战最新一帧同样换用开场播报；最后一条结算播报没有下一手可挂，由终局卡接管文案与配音——`hostNarrationLines` 把它挂在手数 + 1，`stepSeconds`、`mixSpeech`、离线播放器与 `replayData` 的 `finaleAudio*` 都按这一格排。白天最后一位发言者那一手不再携带投票引导、`「2 号被投票放逐」`也不再出现在最后一位投票者的帧上；见[AI 竞技台](ai-arena.md#主持人播报) |
| 2026-10-08 起 | 「谁在执行」成为画面的主角：执行者卡与换手节拍 | 离线回放与视频此前只在两条 26—28px 记分条上用底色标出当前行动者，名字 12—13px、字幕署名同为 12px：缩到手机宽度（393pt ≈ 0.55×）后约 6.5pt，等于看不出是哪家模型在动，而画面最大的字（发言正文）又不带署名。新增执行者卡 `.turn`——席位强调条 + 圆形 logo + 模型名（横屏 30 / 竖屏 32px，狼人杀 26 / 30px），右侧标席位或步数，开局指先手、逐手指本手、终局转金色胜方口径；字幕署名抬到 20—22px 并挂「本手发言」胶囊。换手按「卡先到 → 落子 +0.12s → 台词 +0.22s」排队（视频侧 `markup.mjs` 内联、离线侧 `scene.css` 同名关键帧的 `animation-delay`），执行者卡自身带上滑 + 强调条展开 + logo 微缩放。狼人杀当前席位改蓝环、金框只留给胜方（此前一色两义），侧栏 hero 行整块让给执行者卡；顺带修掉 9 人竖屏席位栅格压住主持人台词。横屏回合记录由 5 手收到 4 手给执行者卡让位。字号下限与换手节拍由 `test/replay.test.mjs` 守住；见[AI 竞技台](ai-arena.md#画面与视频) |
