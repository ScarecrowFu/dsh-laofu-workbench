# 口播视频内容创作指南

`lwb/packs/spoken-video/` 是独立包 `@scitiger-ai/lwb-spoken-video`。先按[快速开始](quickstart.md)安装并加载；这里统一说明八个模块、任务详情和媒体衔接。通用接口见[能力包契约](12-capability-packs.md)。

## 八个模块

| 模块 | 当前行为 |
|---|---|
| 账号定位 | 保存受众、方向和表达边界，AI 可完善；选题提交项目时冻结定位，后续修改不改旧快照 |
| 信号 | 17 个内置来源（16 个公开来源及 SciTiger AI 内容日报），默认启用；采集、启停、收藏、忽略，按来源去重保留最近 7 天；无来源增删改或手动日报导入 UI |
| 选题 | 按账号选渠道、角度、排除信号，确认后补采当天缺失渠道并生成候选；推荐候选进待写稿，其余自行选择。模型内容审核拒绝输入时自动降级：首次保持全部来源的全量最新信号；命中后按 AI 日报、社交热榜优先逐个移除来源（其余来源仍发全量信号），最多移除 8 个来源，再做一次不带渠道信号的诊断；全部失败时提示调整账号定位/角度/历史候选或更换模型 |
| 写稿 | 写稿与失败重试均需确认；AI 稿件自动保存，人工编辑“保存并进入配音”，抽屉可润色检查 |
| 配音 / 字幕 | 项目稿件或独立文本均可创建音频；选 LWB / 百炼 BYOK、系统或上传参考音色；默认生成字幕，字幕失败保留音频，可单独重试 |
| 视频 / 预览 | 关联项目配音继续制作，设置方向、字幕、BGM 和画面要求；DSH 编写 Remotion，经预检、渲染、技术 QC 和独立审片提交 |
| 发布 | 仅展示 QC 通过的视频，管理标题、文案、标签和横竖封面，预览、下载、封面重生或上传；用户到平台发布，无平台直发或队列 |
| 内容安排 | Host 持久化定时任务：账号、来源、执行日/时刻、条数与深度；保留记录，不补跑错过时刻 |

账号定位不等于平台登录或绑定。账号 Tab 只显示名称，默认账号以圆点提示，“通用”放最后；选题与写稿任务列表可看全部账号，其他模块按当前账号筛选。列表先过滤再分页。

阶段标识如下，字幕分支由任务配置决定：

```text
signals → topic → script → voiceover → subtitles → video → qc → packaging
```

每次阶段提交写不可变 artifact，上游更新清除下游当前指针但保留历史；提交使用期望 revision 和幂等键。`packaging` 为终态，须先通过 QC，由受控发布 Agent 写入。不提供人工制作说明替代成片或手工质检覆盖失败。

## 音频、字幕与视频衔接

独立文本与项目配音共享任务入口。列表合并根目录 `audio-tasks.json` 与项目 `media/runs.json`，统一筛选、计数和分页。任务保存稿件快照，历史产物可查看，不可冒充当前配音；编辑只针对当前稿件和音频。

同步只允许匹配当前稿件的音频、字幕。“同步到视频”提交已有本地媒体，不再调供应商或计费。相同产物重复同步幂等，不失效已有下游；字幕改变则视频需重做。`projectSyncError` / `subtitleSyncError` 分别呈现，避免音频成功被字幕同步错误标为整体失败。

TTS、ASR、封面连接独立于场景文本模型。LWB 按服务端积分与权益执行，BYOK 由用户供应商计费；用户确认媒体任务不等于每个网络请求触发 DSH 审批。接入与切换账号见[账号与服务契约](40-lwb-account-model-and-media-services.md)。

## 视频预检与修复

链路为创作 Agent → 可信 AST / CSS 预检 → 渲染与技术 QC → 独立审片。预检拒绝实际或未知的非确定性 CSS，允许明确的 none；不是确定性的完整证明。

可信检查器及 hash 受保护，命令从任务 `task.json` 读取。预检失败最多在同一创作会话修复两轮，未通过不渲染、不提交。取消覆盖 Agent、渲染 CLI 与写入，不能只杀父进程留下渲染子进程。审片失败也不能人工覆盖。

## 执行详情与运行记录

详情统一概览、过程、结果，使用官方 DSH follow/page 与远端 `$mount` / `$stream`。流按序列追踪，保存记录替换临时流；模型、工具和媒体进度来自实际事件，不编造推理。关闭详情停止观察，不取消任务。

快照与错误脱敏并限大小。预览只读数据根内已保存的任务产物，拒绝越界和符号链接；文本最多 2 MiB、媒体最多 80 MiB，不显示密钥或 base64 大块。原生会话与文件由官方对话和右栏处理。

安排选择的深度授权自动推进，可停在选题、写稿、成片质检或发布资料。浏览器关闭不影响运行 Host；Host 停止不调度，也不自动补跑。轮次使用统一任务记录，历史筛选后按 8 / 20 / 50 条分页，详情按需加载。

## 数据与维护

数据在包工作区 `data/`，项目 `data/projects/<project-id>/`，信号与安排 `data/signals.json` / `data/schedules.json`。公开采集只访问 HTTPS，检查 DNS 与重定向，拒绝本机、私网。

卸载保留数据；清空与解绑不同，先停止任务。备份见[运行目录](31-runtime-data-layout.md)，维护见[生命周期](12-capability-packs.md#注册与生命周期)。参考技能、音频出处见[第三方说明](../THIRD_PARTY_NOTICES.md)。
