## 公开代码、服务与能力包

许可证只授予仓库中对应的代码权利，不包含任何服务额度或运营资源：

| 内容 | 当前边界 |
|---|---|
| LWB 工作台、Pack SDK、公开能力包（口播视频内容创作、AI 竞技台） | 随当前源码发布，受根目录许可证约束 |
| LWB 账号、积分、会员、订单和支付 | ATS 私有服务，受单独服务条款约束 |
| LWB 云端模型、配音、字幕和封面服务 | 需要 LWB 账号，并按服务端规则消耗积分或会员权益 |
| 百炼等 BYOK 服务 | 用户自行配置凭据，费用、额度和服务条款由对应供应商决定 |
| 会员能力包（模型博主测评，`model-review`） | 源码在维护者的私有商业仓库中，采用其自身的专有许可，不随本仓库发布，也不受根目录许可证约束 |
| 未发布的其他高级场景能力包 | 不包含在本仓库中，按其私有许可证或商业授权分发 |

公开源码不包含账号余额、会员权益、供应商密钥、云端任务额度或生产环境配置。客户端中的 ATS 协议代码也不授予绕过登录、积分、会员或服务端授权的权利。
